# spicyR: test changes in the co-localisation of cell types between groups of patients

spicyR tests, for every pair of cell types in imaging data with the type
and position of every cell, whether their co-localisation differs
between groups of patients or is associated with survival. Start with
[`spicy()`](https://sydneybiox.github.io/spicyR/dev/reference/spicy.md),
then
[`topPairs()`](https://sydneybiox.github.io/spicyR/dev/reference/topPairs.md),
[`signifPlot()`](https://sydneybiox.github.io/spicyR/dev/reference/signifPlot.md),
[`spicyBoxPlot()`](https://sydneybiox.github.io/spicyR/dev/reference/spicyBoxPlot.md)
and
[`plotImage()`](https://sydneybiox.github.io/spicyR/dev/reference/plotImage.md).
The vignette,
[`vignette("spicyR")`](https://sydneybiox.github.io/spicyR/dev/articles/spicyR.md),
walks through a full analysis.
