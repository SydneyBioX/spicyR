# Package index

## All functions

- [`bind()`](https://sydneybiox.github.io/spicyR/reference/bind.md) :
  Produces a dataframe showing L-function metric for each imageID entry.
- [`colTest()`](https://sydneybiox.github.io/spicyR/reference/colTest.md)
  : Perform a simple wilcoxon-rank-sum test or t-test on the columns of
  a data frame
- [`convPairs()`](https://sydneybiox.github.io/spicyR/reference/convPairs.md)
  : Converts colPairs object into an abundance matrix based on number of
  nearby interactions for every cell type.
- [`diabetesData`](https://sydneybiox.github.io/spicyR/reference/diabetesData.md)
  : Diabetes IMC data in SCE format.
- [`getPairwise()`](https://sydneybiox.github.io/spicyR/reference/getPairwise.md)
  : Get statistic from pairwise L curve of a single image.
- [`getProp()`](https://sydneybiox.github.io/spicyR/reference/getProp.md)
  : Get proportions from a SummarizedExperiment.
- [`imageCrossPlot()`](https://sydneybiox.github.io/spicyR/reference/imageCrossPlot.md)
  : Pairwise cross-plot of spatial associations
- [`plotImage()`](https://sydneybiox.github.io/spicyR/reference/plotImage.md)
  : Plots an image with specified from and to cell types.
- [`signifPlot()`](https://sydneybiox.github.io/spicyR/reference/signifPlot.md)
  : Plots result of signifPlot.
- [`spicy()`](https://sydneybiox.github.io/spicyR/reference/spicy.md) :
  Performs spatial tests on spatial cytometry data.
- [`spicyBoxPlot()`](https://sydneybiox.github.io/spicyR/reference/spicyBoxPlot.md)
  : Plots boxplot for a specified cell-cell relationship
- [`spicyTest`](https://sydneybiox.github.io/spicyR/reference/spicyTest.md)
  : Results from spicy for diabetesData
- [`survBubble()`](https://sydneybiox.github.io/spicyR/reference/survBubble.md)
  : Plots survival results from spicy.
- [`topPairs()`](https://sydneybiox.github.io/spicyR/reference/topPairs.md)
  : A table of the significant results from spicy tests
